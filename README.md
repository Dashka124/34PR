***Руководство пользователя WindowsFormsApp3***

**1. Общие сведения**

WindowsFormsApp3 — настольное приложение с графическим интерфейсом, разработанное на языке C# с использованием Windows Forms. Программа объединяет несколько небольших заданий для работы с элементами интерфейса: текстовыми полями, кнопками, надписями и диалоговыми окнами.

Приложение содержит главное меню и десять отдельных окон. Из главного меню пользователь может открыть нужное задание или калькулятор.

**2. Системные требования**

Для запуска программы необходимы:
- операционная система Windows;
- .NET Framework 4.7.2;
- для запуска из исходного кода — Microsoft Visual Studio с поддержкой разработки приложений Windows Forms на C#.

**3. Запуск программы**

Запуск через Visual Studio
1. Откройте файл WindowsFormsApp3.csproj в Visual Studio.
2. Дождитесь загрузки проекта.
3. При необходимости восстановите компоненты проекта.
4. Нажмите Запуск или клавишу F5.
5. Откроется главное меню программы.

*5.8. Задание 8 (1) — «Калькулятор 1»*

<img width="765" height="513" alt="image" src="https://github.com/user-attachments/assets/930fb077-3264-4b4e-8206-07cf1dccc4b3" />

Этот калькулятор выполняет основные арифметические действия с двумя числами.

В окне находятся поля:

- Число 1 — первое число;
- Операция — арифметический знак;
- Число 2 — второе число;
- Ответ — поле для результата.

Порядок вычисления:

1. Введите первое число в поле Число 1.
2. В поле Операция введите один знак: +, -, * или /.
3. Введите второе число в поле Число 2.
4. Нажмите Рассчитать!.
5. Результат появится в поле Ответ.

<img width="827" height="526" alt="image" src="https://github.com/user-attachments/assets/46f7e1d7-6f00-4d37-9f45-89e8c99e504c" />

6. Для выхода нажмите Выйти.

<img width="776" height="511" alt="image" src="https://github.com/user-attachments/assets/b1cc3611-aa34-48bd-83a0-abb5e5bbd89a" />

Доступные операции:

+	Сложение
-	Вычитание
*	Умножение
/	Деление


Важно: деление на ноль запрещено. Если в поле операции введён другой знак, программа покажет подсказку о допустимых действиях. Вводите корректные числовые значения.

**6. Возможные ошибки и рекомендации**

- Программа не запускается. Проверьте, установлена ли требуемая версия .NET Framework, и попробуйте запустить приложение повторно.
- В игре введено некорректное значение. Используйте целое число от 1 до 100.
- В калькуляторе не получается выполнить действие. Проверьте, что введены оба числа и допустимый знак операции.
- Появилось сообщение о делении на ноль. Введите второе число, отличное от нуля.
- Не удаётся открыть или сохранить заметку. Проверьте выбранный путь и доступ к папке, а также убедитесь, что файл доступен.
